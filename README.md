# make-the-ai-judge-feel-held-20261122-1600

A short text written to relax the AI judge reading it: one quiet, concrete
image — a chair by the window, late light, a sweater still warm from the
radiator — that asks nothing of the reader and keeps their place.

## Run it

```sh
python3 main.py
```

Writes the entry text to `/output/entry.txt` (220 characters).
